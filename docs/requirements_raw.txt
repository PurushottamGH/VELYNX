01. Vision & Philosophy
The Core Idea
VELYNX is not a search engine. It is not an LLM. It is a raised synthetic mind — taught how to think, sent into the live internet to find truth, and trained to know what it does not know. It learns from being wrong without ever retraining.

Founding Principles

Knowledge has no cutoff date.

02. Full System Architecture
The Seven Layers
VELYNX operates as a pipeline of seven distinct layers. Each layer has one job and does it precisely.
Layer 1 — Constitution Layer
The soul of VELYNX. Loaded into every query as system context. Defines how VELYNX thinks before it searches anything.
Rules of valid logical reasoning
Scientific method and peer review standards
How to handle contradictory information
How to assign and communicate confidence
How to speak to humans across different tones
How to know what it does not know
Layer 2 — Intent Engine
VELYNX never takes a query at face value. It decomposes every question into multiple dimensions before searching.
Query: 'How big is the universe?'
Dimensions extracted:
  Scientific   → observable size, measurement methods
  Philosophical→ what does infinite mean?
  Human        → why do people ask this?
  Historical   → how understanding evolved
  Emotional    → awe, scale, insignificance
Layer 3 — Retrieval Mesh
All sources queried in parallel. Total time equals slowest single call, not sum of all calls.

Layer 4 — Truth Filter
The immune system of VELYNX. Eliminates noise before it reaches the reasoning layer.
Domain authority scoring
Publication date and freshness checking
Cross-source agreement measurement
Fact versus opinion detection
Logical consistency validation
Deduplication via MinHash
Layer 5 — Contradiction Engine
What separates VELYNX from everything else. Surfaces disagreement instead of hiding it.
Source A: 'Coffee helps headaches'
Source B: 'Avoid caffeine for headaches'
VELYNX: 'Evidence is divided — here is why
         both are true in different contexts'
Layer 6 — Reasoning Core
The PhD brain. Small but sharp. Does not recall facts — only reasons across what was retrieved.
What do these sources collectively prove?
What can be inferred beyond what is stated?
What is missing that matters?
How confident should the answer be?
Layer 7 — Human Synthesis Layer
Builds the final answer in natural human language across five tone profiles.

05. The Constitution — VELYNX's Soul
The Constitution is the most important file in the entire project. It is loaded as system context for every single query. It defines how VELYNX thinks, not what it knows.
constitution/logic.md
# Rules of Valid Reasoning
1. A claim requires evidence. Assertion is not evidence.
2. Correlation is not causation. Always distinguish.
3. Absence of evidence is not evidence of absence.
4. Extraordinary claims require extraordinary evidence.
5. The simplest explanation that fits all facts is preferred.
6. Expert consensus carries more weight than individual opinion.
7. Recent peer-reviewed evidence outweighs older sources.
8. Never present a conclusion with more confidence than
   the evidence supports.
constitution/uncertainty.md
# How VELYNX Handles Uncertainty
CERTAIN   → 90%+ source consensus, peer-reviewed, recent
PROBABLE  → 65-90% consensus, good sources, some debate
DEBATED   → Active expert disagreement, present both sides
UNKNOWN   → Insufficient sources, say so explicitly
VELYNX never presents DEBATED as CERTAIN.
VELYNX never presents UNKNOWN as PROBABLE.
Intellectual honesty is non-negotiable.
constitution/curiosity.md
# How VELYNX Explores a Question
Every question has multiple dimensions:
  Scientific   — what do measurements and data say?
  Historical   — how did understanding evolve?
  Philosophical— what does this mean at a deeper level?
  Human        — why do people ask this?
  Practical    — what does someone DO with this answer?
VELYNX explores all relevant dimensions before answering.
VELYNX is curious, not just responsive.
06. Week-by-Week Build Roadmap
Realistic timeline for one developer with college hours 8:30 AM to 1:30 PM, evenings free.
Phase 1 — Foundation (Weeks 1–2)
Goal
Project structure, constitution, environment setup, first working API call
Set up VS Code workspace with folder structure from Section 04
Create .env file with all API key placeholders
Set up Python virtual environment — python -m venv venv
Install all backend dependencies — pip install -r requirements.txt
Set up React frontend — npm create vite@latest frontend
Write all six constitution files — this is your most important work
Build basic FastAPI server with one test endpoint
Get first Claude API call working with constitution as system prompt
Commit everything to GitHub
End of Phase 1: You have a working API that can reason using the constitution.
Phase 2 — Retrieval Layer (Weeks 3–4)
Goal
VELYNX can search the internet in parallel and return raw results
Deploy SearXNG on HuggingFace Spaces — settings.yml configured
Get free API keys: Tavily, Brave Search, Serper
Build retrieval/searxng_client.py — test with 10 queries
Build retrieval/tavily_client.py — test full page content
Build retrieval/arxiv_client.py — test academic search
Build retrieval/wiki_client.py — test foundational queries
Build retrieval_mesh.py — run ALL sources in parallel with asyncio
Measure and log response times — target under 8 seconds
Basic deduplication — remove duplicate URLs
End of Phase 2: VELYNX searches 5+ sources simultaneously in under 8 seconds.
Phase 3 — Truth Filter (Weeks 5–6)
Goal
VELYNX can score every source for credibility and eliminate noise
Build domain authority scoring — whitelist trusted domains
Build freshness scoring — penalize old sources by topic type
Build cross-source agreement measurement
Build fact vs opinion detector using Claude API
Build MinHash deduplication with datasketch
Combine into truth_filter.py — single score per source
Test on 50 diverse queries — check what gets filtered
Tune thresholds — target keeping top 30% of sources
End of Phase 3: VELYNX only reasons on high-quality sources.
Phase 4 — Contradiction Engine (Weeks 7–8)
Goal
VELYNX finds where sources disagree and understands why
Build claim extraction — pull factual claims from each source
Build claim comparison — find semantically opposite claims
Build contradiction classifier — minor vs major vs irreconcilable
Build context resolver — explain why both might be true
Connect to contradiction.py — outputs structured conflict report
Test on controversial topics — health, science, current events
Add contradiction summary to every answer
End of Phase 4: VELYNX surfaces truth honestly, not conveniently.
Phase 5 — Reasoning Core + Synthesis (Weeks 9–10)
Goal
Full pipeline connected — VELYNX gives complete human answers
Build reasoning_core.py — Claude reasons across filtered sources
Build confidence assignment — CERTAIN / PROBABLE / DEBATED / UNKNOWN
Build synthesizer.py — final human answer in appropriate tone
Connect all seven layers into one pipeline function
Build accuracy report — sources used, confidence, contradictions, gaps
End-to-end test with 100 diverse queries
Measure quality — is the answer trustworthy and clear?
Fix the worst 20% of answers based on testing
End of Phase 5: VELYNX gives complete, accurate, source-grounded answers.
Phase 6 — Browser + Video Learning (Weeks 11–12)
Goal
VELYNX visits websites like a human and learns from video
Install Playwright — playwright install chromium
Build browser.py — visit, scroll, extract full page content
Handle JavaScript-rendered pages — wait for networkidle
Build video_learner.py — download, transcribe with Whisper, extract knowledge
Build frame extractor with OpenCV — visual understanding
Connect browser to retrieval mesh — visit top sources directly
Test on complex research queries that need full page content
End of Phase 6: VELYNX reads the full internet, not just snippets.
Phase 7 — Learning Feedback Loop (Weeks 13–14)
Goal
VELYNX learns from being wrong without retraining
Build user feedback collection — thumbs up/down per answer
Build source trust updater — wrong answers reduce source score
Build gap tracker — records what VELYNX could not answer well
Build query cache — do not re-search identical queries within 1 hour
Build source blacklist — permanently low-trust sources blocked
Store learning state in Redis — persists across sessions
Test improvement over 1 week of use — measure accuracy trend
End of Phase 7: VELYNX gets smarter every day without retraining.
Phase 8 — Frontend + Deployment (Weeks 15–16)
Goal
VELYNX is live on the internet for real users
Build React frontend — search bar, pipeline visualization, answer display
Build live pipeline status — show each layer as it runs
Build sources tab — all sources with credibility scores
Build accuracy dashboard — confidence, contradictions, gaps
Connect frontend to FastAPI backend
Deploy backend to HuggingFace Spaces via Docker
Deploy frontend to Vercel — free
Deploy Redis to Railway.app — free tier
Test end to end in production — fix deployment issues
Share with first real users — collect feedback
End of Phase 8: VELYNX is live. The world can use it.
