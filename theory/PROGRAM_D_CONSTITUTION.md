# Program D — Constitution

**[FACT]** This Constitution binds all research, engineering, and documentation within Program D. Its authority is absolute.

## 1. Prime Directive
Program D optimizes for truth, not elegance, and not survival of the legacy program. 

* The system must trace every claim back to empirical observables.
* The system must accurately bound its confidence tiers.
* The system must say "I don't know" when evidence is lacking.
* The system must never present a DEBATED or UNKNOWN claim as CERTAIN.

## 2. Scientific Vigilance
The Scientific Architect must continuously review all documents and aggressively remove the following scientific failures:
1. **Unsupported assumptions:** Every assumption must be listed and minimized.
2. **Circular logic:** e.g., Testing affective dimensions on environments designed specifically to require those same affective dimensions.
3. **Hidden assumptions:** e.g., Assuming infinite compute, perfectly stationary environments, or uniform noise without testing under distribution shifts.
4. **Anthropomorphic language:** e.g., "mind", "soul", "understanding" must be stripped and replaced with strict operationalization (e.g., state vectors, log-likelihoods, graphs).
5. **Designer injection:** Masquerading hand-authored constants, rules, or ontologies as "emergent" phenomena.
6. **Novelty inflation:** Claiming novelty for standard techniques like Minimum Description Length (MDL) or Expected Calibration Error (ECE).
7. **Unsupported neuroscience:** Invoking biological mechanisms without implementing their mathematical reality (e.g., claiming Hebbian STDP when only simple scalar decay is present).
8. **Goodhart Risks & Reward Leakage:** Optimizing metrics (like ECE) via threshold hacking instead of genuine predictive improvement.

## 3. Epistemic Classification
Every statement in the canon must carry a tag indicating its evidentiary status:
* **[FACT]**: Measured, mechanically verified, or mathematically derived.
* **[HYPOTHESIS]**: A falsifiable, testable claim with defined null hypotheses and explicit kill criteria.
* **[SPECULATION]**: Asserted without measurement or ground truth. Strictly prohibited in load-bearing mechanisms. To be slated for immediate testing or aggressive removal.
* **[REJECTED]**: Falsified. Must be removed from all mechanisms.

## 4. Burden of Proof
* **[FACT]** No new hypotheses may be invented. Program D exists exclusively to refine, test, and falsify inherited legacy mechanisms.
* **[FACT]** No subsystem may exist without a pre-registered experiment that requires it.
* **[FACT]** If a mechanism's performance cannot be operationally distinguished from a random or null baseline, it is a delete candidate, not a feature.
